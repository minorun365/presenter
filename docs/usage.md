# 使い方の詳細

## 書き出し

```bash
python3 present.py <原稿.md> [--minutes 分] [--theme テーマ.css] [--chapter-class クラス] [--open]
```

| オプション | 既定 | 内容 |
|---|---|---|
| `--minutes` | 30 | 持ち時間の初期値（分）。操作画面でも変えられる |
| `--theme` | なし | テーマの CSS ファイル |
| `--chapter-class` | lead top crosshead | 章の切れ目として扱うスライドのクラス。空白区切りで複数書ける |
| `--open` | なし | 書き出したあと、既定のブラウザで操作画面を開く |

書き出し先は原稿と同じフォルダの `<名前>.present.html` です。画像は原稿からの相対パスで読み込むため、HTML は原稿と同じ場所に置いたまま使います。

原稿の外のフォルダにある画像、英数字以外を含むファイル名の画像、CSS の `url()` で読み込む背景画像は、`present-assets/` へコピーして参照先を書き換えます。コピー先のファイル名は中身から作るので、画像を差し替えて書き出し直せば名前も変わります。

## テーマ

`--theme` を省略すると、原稿の先頭の `theme:` に書いた名前で CSS を探します。探す順番は、原稿と同じフォルダ、その中にある `themes/`、このリポジトリの `themes/` です。いずれにも見つからず、名前が Marp の組み込みテーマ（default・gaia・uncover）なら、そのテーマで書き出します。

見本の `example/themes/minorun-glass.css` は、白地にガラス風のカードを重ねるテーマです。表紙の `top`、中扉の `crosshead`、締めの `end` のクラスと、手順の `.steps`、流れ図の `.flow` といった部品を用意しています。フォントは Google Fonts の Noto Sans JP と M PLUS Rounded 1c を読み込み、オフラインのときはヒラギノなど手元のフォントで表示します。

## 画面

書き出した HTML は、URL の `view` に応じて3つの画面に切り替わります。

| 画面 | URL | 役割 |
|---|---|---|
| 一覧 | `?view=overview` | 全ページを3列で並べる。URL を開いたときの最初の画面 |
| 操作画面 | `?view=presenter` | 手元で残り時間と前後のページを見ながら送る |
| 投影画面 | `view` なし | 聴衆に見せる1枚表示。全画面にするのはこのウィンドウ |

一覧でページを1回押すと選択し、2回押すとそのページから操作画面で開きます。上の帯の「1枚ずつ見る」も同じです。どのウィンドウも同じページを表示するように同期します。

## 投影の流れ

操作画面か一覧で「投影」を押すと、投影画面を別ウィンドウで開きます。

ディスプレイが2枚あるときは、Chrome の Window Management API を使い、もう1枚のディスプレイいっぱいにウィンドウを開きます。初回だけ「ウィンドウの管理」の許可を求められ、許可した直後はクリックの有効期限が切れるため、もう一度「投影」を押してください。

開いた直後は投影画面のウィンドウがキー入力を受け付ける状態になっているため、Enter（ほかのキーでも可）を押すと全画面になり、キー入力は操作画面へ戻ります。ページから直接、全画面のウィンドウを開く仕組みがブラウザにないため、このキー操作が1回必要です。Chrome のサイト設定で「自動全画面」を許可したサイトでは、キーを押さなくても全画面になります。

キー入力が操作画面に残ったまま Enter を押した場合は、投影画面のウィンドウへキー入力を移して案内を出すので、もう一度 Enter を押します。

ディスプレイが1枚のときは、ウィンドウを増やさず、「投影」を押したウィンドウそのものが全画面のスライドになります。← →（↑ ↓・スペース・PageUp / PageDown でも可）でページを送り、Esc で元の画面の同じページに戻ります。

オンライン会議で画面を共有する場合は、先に共有を始めてから「投影」を押します。ウィンドウが1つなので、画面全体の共有でもウィンドウの共有でも、手元と同じ画面が映ります。

全画面に出るのはスライドだけで、残り時間やページ番号、ボタンは出ません。マウスの矢印も、2秒動かさなければ消えます。残り時間は Esc で戻った操作画面で確かめます。

ディスプレイが2枚あるのに許可しなかったときは、投影画面を通常の別ウィンドウで開き、下部に「全画面にする」と「このまま使う」のボタンを表示します。

投影画面が開いている間は、操作画面のボタンが「投影を終える」に変わり、押すと投影画面のウィンドウを閉じます。

## タイマーと進み具合のバー

開始前は、残り時間のうち分の数字が入力欄になっています。数字を入力して Enter を押すと、持ち時間を設定して開始します。数字のあたりをクリックしても開始と一時停止を切り替えられ、止めている間だけ「リセット」が表示されます。

残り時間が持ち時間の15%か5分のどちらか短いほうを下回るとオレンジに、時間を超えると赤に変わります。タイマーの状態はブラウザに保存するので、ウィンドウを再読み込みしても続きからカウントします。

バーの塗りつぶしはページの進み具合、針は経過時間を表します。右上の「◯分 遅れ」「◯分 先行」は、全ページを同じ長さで話すと仮定した目安です。バーの上には、現在の章の見出しを表示します。章の切れ目は最初のページと、`--chapter-class` で指定したクラスのページです。

## パートの区切り

原稿と同じフォルダに `present-parts.txt` を置くと、バーをパートごとに区切り、下にパート名を薄い文字で表示します。1行につき1パートを書き、パート名と先頭スライドの見出しをコロンでつなぎます。見出しは先頭の数文字だけで指定できます。スライドに h1 があれば h1 を、なければ h2 を見出しとして読み込み、空白や `<br>` などのタグを取り除いて照合します。

```text
はじめに: ヘラブナ釣りの楽しさ
ヘラブナとは: ヘラブナ釣り知ってますか
楽しさ: 何がそんなに楽しいの
始め方: 今度の週末始めてみよう
```

見出しが原稿に見つからない行があると、書き出しを中断してその行を表示します。ファイルがない場合は、バーを区切らずに1本で表示します。

## 前後のページの帯

帯には、現在のページの前を1〜2枚、残りに後ろのページを並べます。枚数は帯の幅で決まります。帯の上で横スクロールすると前後のページを確認でき、押したページへ移動します。スクロールしても投影画面は変わらず、ページが変わるか10秒操作しなければ現在のページの周辺へ戻ります。

## キー操作

| キー | 動作 |
|---|---|
| → / ← | 次のページ / 前のページ |
| Enter | 投影画面がまだ全画面でないとき、投影画面のウィンドウへキー入力を移す |
| o | Marp 標準の一覧を重ねる |

操作画面の入力欄とボタンの上では、キー操作でページを送りません。

## 話者ノート

原稿に HTML コメントで書いた話者ノートがあると、操作画面の下にノートの欄を表示します。ノートが1つもない原稿では、欄を表示しません。

## 動作環境

Chrome（Chromium 系のブラウザ）で使ってください。もう1枚のディスプレイへ投影画面を出す機能は Window Management API を使っているため、ほかのブラウザでは通常の別ウィンドウで開きます。
