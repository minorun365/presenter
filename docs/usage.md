# 使い方の詳細

## 書き出し

```bash
python3 present.py <原稿.md> [--minutes 分] [--theme テーマ.css] [--chapter-class クラス] [--open]
```

| オプション | 既定 | 内容 |
|---|---|---|
| `--minutes` | 30 | 持ち時間の初期値（分）。操作画面でも変えられる |
| `--theme` | なし | テーマの CSS ファイル |
| `--chapter-class` | lead top crosshead | 章の切れ目として扱うスライドのクラス。空白区切りで複数書ける |
| `--open` | なし | 書き出したあと、既定のブラウザで操作画面を開く |

書き出し先は原稿と同じフォルダの `<名前>.present.html` です。画像は原稿からの相対パスで読むので、HTMLは原稿の隣に置いて使います。

原稿の外のフォルダにある画像、英数字以外を含むファイル名の画像、CSS の `url()` で読む背景画像は、`present-assets/` へ写して参照を付け替えます。写しの名前は中身から作るので、画像を差し替えて書き出し直せば名前も変わります。

## テーマ

`--theme` を省くと、原稿の先頭の `theme:` に書いた名前で CSS を探します。探す順番は、原稿と同じフォルダ、原稿の隣の `themes/`、このリポジトリの `themes/` です。見つからず、名前が Marp の組み込みテーマ（default・gaia・uncover）なら、そのテーマで書き出します。

見本の `example/themes/minorun-glass.css` は、白地にガラス風のカードを重ねるテーマです。表紙の `top`、中扉の `crosshead`、締めの `end` のクラスと、手順の `.steps`、流れ図の `.flow` といった部品を持っています。書体は Google Fonts の Noto Sans JP と M PLUS Rounded 1c を読み込み、オフラインのときはヒラギノなど手元の書体で表示します。

## 画面

書き出したHTMLは、URL の `view` で3つの画面に切り替わります。

| 画面 | URL | 役目 |
|---|---|---|
| 一覧 | `?view=overview` | 全ページを3列で並べる。URL を開いたときの最初の画面 |
| 操作画面 | `?view=presenter` | 手元で残り時間と前後のページを見ながら送る |
| 投影画面 | `view` なし | 聴衆に見せる1枚表示。全画面にするのはこの窓 |

一覧でページを1回押すと選び、2回押すとそのページから操作画面で開きます。上の帯の「1枚ずつ見る」も同じです。どの窓も同じページを指すように同期します。

## 投影の流れ

操作画面か一覧で「投影」を押すと、投影画面を別の窓で開きます。

ディスプレイが2枚あるときは、Chrome の Window Management API で、もう1枚のディスプレイいっぱいに窓を開きます。初回だけ「ウィンドウの管理」の許可を聞かれ、許可した直後はクリックの有効期限が切れるので、もう一度「投影」を押してください。

開いた直後は投影画面の窓にキー入力が向いているので、Enter（ほかのキーでも可）を押すと全画面になり、キー入力は操作画面へ戻ります。ページから最初から全画面の窓を開く手段がブラウザに無いため、このキー操作が1回要ります。Chrome のサイト設定で「自動全画面」を許可したサイトでは、キーを押さなくても全画面になります。

キー入力が操作画面に残ったまま Enter を押した場合は、投影画面の窓へキー入力を移して案内を出すので、もう一度 Enter を押します。

ディスプレイが1枚のときや許可しなかったときは、投影画面を普通の別窓で開き、下に「全画面にする」と「このまま使う」のボタンを出します。

投影画面が開いている間、操作画面のボタンは「投影を終える」に変わり、押すと投影画面の窓を閉じます。

## タイマーと進み具合のバー

開始前は残り時間の分の数字が入力欄になっています。数字を打って Enter を押すと、持ち時間を決めて開始します。数字のあたりをクリックしても開始と一時停止を切り替えられ、止めている間だけ「リセット」が出ます。

残り時間が持ち時間の15%か5分のどちらか短いほうを切るとオレンジに、時間を超えると赤に変わります。タイマーの状態はブラウザに保存するので、窓を読み込み直しても続きから数えます。

バーの塗りはページの進み、針は経過時間です。右上の「◯分 遅れ」「◯分 先行」は、全ページを同じ長さで話すと仮定した目安です。バーの上には、いまいる章の見出しを出します。章の切れ目は最初のページと、`--chapter-class` で指定したクラスのページです。

## パートの区切り

原稿と同じフォルダに `present-parts.txt` を置くと、バーをパートごとに区切り、下にパート名を薄い文字で出します。1行に1パートで、パート名と、そのパートの先頭スライドの見出しをコロンでつなぎます。見出しは頭の数文字で大丈夫です。スライドに h1 があれば h1 を、無ければ h2 を見出しとして読み、空白と `<br>` などのタグは取り除いて比べます。

```text
はじめに: ヘラブナ釣りの楽しさ
ヘラブナとは: ヘラブナ釣り知ってますか
楽しさ: 何がそんなに楽しいの
始め方: 今度の週末始めてみよう
```

見出しが原稿に見つからない行があると、書き出しを止めてその行を表示します。ファイルが無ければ、バーは区切らずに1本です。

## 前後のページの帯

帯には、今のページの前を1〜2枚、残りを後ろに並べます。枚数は帯の幅で決まります。帯の上で横スクロールすると前後のページをめくれ、押したページへ飛びます。めくっても投影画面は変わらず、ページが変わるか10秒さわらなければ今のページの周りへ戻ります。

## キー操作

| キー | 動作 |
|---|---|
| → / ← | 次のページ / 前のページ |
| Enter | 投影画面がまだ全画面でないとき、投影画面の窓へキー入力を移す |
| o | Marp 標準の一覧を重ねる |

操作画面の入力欄とボタンの上では、キー操作でページは送りません。

## 話者ノート

原稿に HTML コメントで書いた話者ノートがあると、操作画面の下にノートの欄を出します。ノートが1つも無い原稿では欄を出しません。

## 動作環境

Chrome（Chromium 系のブラウザ）で使ってください。もう1枚のディスプレイへ投影画面を出す機能は Window Management API に依っており、ほかのブラウザでは普通の別窓で開きます。
