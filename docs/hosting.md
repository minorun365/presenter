# ホスティングして使う

HTML を書き出す際、原稿のフォルダの外にあった画像も `present-assets/` へコピーされるので、`<名前>.present.html`・`present-assets/`・原稿が参照している画像を含むフォルダを丸ごと置けば配信できます。S3 や GitHub Pages のような静的ホスティングなら、どこでも使えます。

配信した URL を開くと、最初は全ページの一覧が表示されます。発表する PC でその URL を開き、「投影」を押せば手元の操作画面と投影画面がそろうので、発表用のファイルを持ち歩く必要はありません。

## iframe の中で開いたとき

ビューアやポータル上で、ページを iframe 内に埋め込んで表示することがあります。その場合、一覧上部の帯と操作画面の上部パネルを少し下げ、埋め込み側が左上や右上に配置するボタンと重ならないようにします。また、Marp は iframe 内の一覧を別の画面の上に重ねたものと誤認して、閉じるボタンだけの帯をもう1枚出すので、それも取り除きます。

投影画面は別のウィンドウで開くので、iframe の外の通常のウィンドウとして全画面にできます。

## HTML共有くんと組み合わせる

[HTML共有くん](https://github.com/minorun365/html-share) は、AIコーディングエージェントに作らせた HTML を1か所にためて、スマホからも読めるようにするセルフホスト型のツールです。書き出した発表用HTMLを共有くんにページとして登録すると、次のような使い方ができます。

- 発表前に、スマホで一覧を開いて流れを見返す
- 会場の PC や借りた PC で共有くんを開き、そのページから投影を始める
- 発表後に、期限付きの共有URLで参加者にスライドを渡す
