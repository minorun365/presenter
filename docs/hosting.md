# ホスティングして使う

書き出したHTMLは、原稿のフォルダの外にあった画像も `present-assets/` へ写すので、`<名前>.present.html`・`present-assets/`・原稿が参照している画像を含むフォルダを丸ごと置けば配信できます。S3 や GitHub Pages のような静的ホスティングなら、どこでも使えます。

配信した URL を開くと、最初は全ページの一覧になります。発表する PC でその URL を開き、「投影」を押せば手元の操作画面と投影画面がそろうので、発表用のファイルを持ち歩く必要がありません。

## iframe の中で開いたとき

ビューアやポータルが、ページを iframe に入れて見せることがあります。その場合、一覧の上の帯と操作画面の上のパネルを少し下げ、埋め込み側が左右上に重ねるボタンと重ならないようにします。Marp は iframe の中の一覧を別の画面の上に重ねたものと取り違えて、閉じるボタンだけの帯をもう1枚出すので、それも取り除きます。

投影画面は別の窓で開くので、iframe の外の普通の窓として全画面にできます。

## HTML共有くんと組み合わせる

[HTML共有くん](https://github.com/minorun365/html-share) は、AIコーディングエージェントに作らせたHTMLを1か所へためて、スマホからも読めるようにするセルフホスト型のツールです。書き出した発表用HTMLを共有くんにページとして登録すると、次のような使い方ができます。

- 発表前に、スマホで一覧を開いて流れを見返す
- 会場のPCや借りたPCで共有くんを開き、そのページから投影を始める
- 発表後に、期限付きの共有URLで参加者へスライドを渡す
